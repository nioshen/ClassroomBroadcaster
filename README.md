# ClassroomBroadcaster 教室直播 使用說明

本工具把教師電腦的畫面，透過區網即時直播給 60 台學生電腦。學生用 Chrome 或 Edge 打開網頁，就能一邊看一邊寫程式。

適用 **Windows 10（1809 以上）／Windows 11**。學生電腦**完全不用安裝任何東西**。

本工具有兩種版本，學生觀看的網址都一樣：`http://主教師機IP:8080/`。

下載時有兩個 zip 可以選：**`ClassroomBroadcaster-lite.zip`**（只有簡易版，約 40 KB）和 **`ClassroomBroadcaster-full.zip`**（OBS 版，也包含簡易版，約 235 MB）。

| | **簡易版**（Lite） | **OBS 版**（完整版） |
|---|---|---|
| 需要準備什麼 | 不用準備，解壓縮就能用 | 先在有網路的電腦執行一次 `build.bat` |
| 教師機需要安裝 | 不用（只用內建的 Edge） | 不用（OBS 已內含） |
| 延遲 | 約 0.2–0.5 秒 | 約 0.2–0.5 秒 |
| 開始方式 | 點捷徑後按「開始分享畫面」 | 點捷徑就自動開播 |
| 適合情境 | 臨時使用、任何電腦 | 固定教室長期使用、想用 OBS 進階功能 |

---

## 簡易版（不用下載任何東西）

### 主教師機

1. 把 zip **解壓縮**到任意位置，例如 `C:\ClassroomBroadcaster\`。
2. 雙擊 **`lite-start.bat`**。
   - 第一次使用會跳出一次「使用者帳戶控制」視窗，請按「是」，讓程式設定防火牆。
   - 電腦有多張網卡時，會列出各張網卡的 IP 讓你按數字鍵選擇學生電腦所在的教室網路（10 秒內沒選就用預設值，下次預設上次的選擇）。
   - 之後可以直接點桌面上的「教室直播（簡易版）」。
3. 程式會開啟教師端視窗，按 **「開始分享畫面」**，選「整個螢幕」，再按「分享」。
4. 開始直播後，可以把教師端視窗縮到最小，不要把它關掉。
5. 黑色狀態視窗會顯示學生觀看網址、觀看人數和流量。要結束直播時，按 `Q` 或直接關閉這個視窗。

### 第二教師機（選用）

雙擊 **`lite-teacher2.bat`**。第一次會詢問主教師機的 IP，輸入後按「開始分享畫面」即可。

這台電腦的畫面會出現在「教師 2」頻道。

## OBS 版（完整版）

### 只需做一次：產生完整版

在**任何一台有網路**的 Windows 電腦上，雙擊 **`build.bat`**。不需要系統管理員權限。

它會自動下載以下檔案，並驗證檢查碼和數位簽章：

- MediaMTX
- OBS Studio 免安裝版
- Microsoft VC++ 執行階段

全部約 190 MB。完成後可以選擇產生 `ClassroomBroadcaster-full.zip`，同時也會產生只有簡易版的 `ClassroomBroadcaster-lite.zip`（只要簡易版時，雙擊 `build-lite.bat` 即可，不需網路）。之後把這個資料夾或 zip 用隨身碟複製到各教師機，就**不需要再下載或安裝**。

### 主教師機

1. 雙擊 **`start.bat`**，按「是」允許系統管理員權限。
2. 第一次執行時會自動完成：
   - 設定防火牆。
   - 依螢幕解析度建立 OBS 設定。
   - 電腦有多張網卡時，讓你選擇學生電腦所在的教室網路（同簡易版）。
   - 在桌面建立「教室直播 開始／停止」捷徑。
3. 程式會自動開啟 OBS 並開始直播。之後上課只要點桌面的 **「教室直播 開始」**。
4. 要結束直播時，在黑色視窗按 `Q`，或點「教室直播 停止」。

### 第二教師機（選用）

雙擊 **`teacher2.bat`**。第一次會詢問主教師機的 IP，之後就會自動開啟 OBS，推流到「教師 2」頻道。

## 學生電腦

- 開 Chrome 或 Edge，進入 `http://主教師機IP:8080/`。網址會顯示在主教師機的黑色狀態視窗上。
- 也可以用派送軟體，把啟動後產生的 `deploy\教室直播.url` 發到學生桌面，或做進還原卡的母片。
- 播放頁功能：
  - **子母畫面**（`P`）：小視窗會浮在編輯器上方。
  - **半螢幕**：按 `Win + ←／→`。
  - **滾輪放大**：放大游標所在位置，放大後可以拖曳移動；雙擊可放大 2 倍或還原。
  - **切換教師**：按 `1`／`2`。
  - **重新連線**：按 `R`。斷線時也會自動重連。

## 資料夾內容

| 檔案 | 用途 |
|---|---|
| `lite-start.bat` | 簡易版：主教師機 |
| `lite-teacher2.bat` | 簡易版：第二教師機 |
| `build.bat` | OBS 版：在有網路的電腦執行一次，產生完整版（同時產生簡易版 zip） |
| `build-lite.bat` | 只打包簡易版 zip（不需網路） |
| `start.bat`／`stop.bat` | OBS 版：主教師機啟動／停止 |
| `teacher2.bat` | OBS 版：第二教師機 |
| `settings.psd1` | 設定（一般不用修改） |
| `lite\` | 簡易版的直播伺服器與網頁 |
| `www\`、`mediamtx.yml` | OBS 版的學生播放頁與伺服器設定 |
| `obs\`、`mediamtx.exe`、`vcredist\` | 執行 build.bat 之後才會出現 |

## 導入測試清單

- [ ] 單機測試：在主教師機另開瀏覽器，進入 `http://localhost:8080/`，確認延遲小於 1 秒、程式碼文字清楚。
- [ ] 5–10 台學生機：確認都能觀看；學生機重開機（被還原卡還原）後，捷徑仍然可以使用。
- [ ] 全班 60 台：觀察狀態視窗的總流量（約 60 × 2–4 Mbps）。
- [ ] 中斷再恢復：停止分享或關掉 OBS 後再開，學生畫面會自動恢復。

## 疑難排解

| 狀況 | 處理方式 |
|---|---|
| 學生顯示「無法連線到教師電腦」 | 確認學生電腦 ping 得到主教師機；重新啟動一次，讓程式重新設定防火牆。 |
| 學生顯示「尚未開始直播」 | 簡易版：確認教師端已按「開始分享畫面」。OBS 版：確認 OBS 正在直播。 |
| 字太糊 | 簡易版：教師端改選「高畫質」。兩種版本都建議把 VS Code 放大到 125–150%。 |
| 部分學生卡頓 | 簡易版：教師端改選「省頻寬」。也請檢查交換器之間的串接線是否為 Gigabit。 |
| 「埠 8080 已被使用」 | 簡易版和 OBS 版不能同時開，請先關閉其中一個；也可以在 `settings.psd1` 修改 `HttpPort`。 |
| IP 選錯或偵測錯誤（例如抓到虛擬網卡） | 重新啟動後在網卡清單選正確的；或在 `settings.psd1` 的 `ServerIP` 直接填入正確 IP，之後就不會再詢問。 |
| OBS 的「螢幕擷取」是黑畫面 | 在 OBS 雙擊「螢幕擷取」，重新選擇要擷取的螢幕。 |
| OBS 版顯示「直播中」，但學生畫面全黑 | 通常是 UDP 8189 被學校網路擋住，可以改用簡易版（只用 TCP 8080）。 |

## 使用的連接埠

- **簡易版**：只用 TCP 8080。
- **OBS 版**：TCP 8080（播放頁）、TCP 8889 和 UDP 8189（WebRTC）、TCP 8888（相容模式）。
