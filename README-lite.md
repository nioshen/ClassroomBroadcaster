# ClassroomBroadcaster 教室直播（簡易版 Lite）

本工具把教師電腦的畫面，透過區網即時直播給 60 台學生電腦。學生用 Chrome 或 Edge 打開網頁，就能一邊看一邊寫程式。

這是**簡易版**：只用 Windows 內建的 PowerShell 與 Microsoft Edge，**解壓縮就能用，不需要下載或安裝任何東西**。延遲約 0.3–0.5 秒。

適用 **Windows 10（1809 以上）／Windows 11**。學生電腦**完全不用安裝任何東西**。

> 需要用 OBS 推流（場景切換、加字幕等進階功能）時，請改用完整版 `ClassroomBroadcaster-full.zip`，完整版也包含這個簡易版。

---

## 主教師機

1. 把 zip **解壓縮**到任意位置，例如 `C:\ClassroomBroadcaster-lite\`。
2. 雙擊 **`lite-start.bat`**。
   - 第一次使用會跳出一次「使用者帳戶控制」視窗，請按「是」，讓程式設定防火牆。
   - 電腦有多張網卡（例如有線網路＋USB 網卡）時，黑色視窗會列出各張網卡的 IP，請按數字鍵選擇學生電腦所在的教室網路。10 秒內沒有選擇會自動使用預設值，下次會預設上次的選擇。
   - 之後可以直接點桌面上的「教室直播（簡易版）」。
3. 程式會開啟教師端視窗，按 **「開始分享畫面」**，選「整個螢幕」，再按「分享」。
4. 開始直播後，可以把教師端視窗縮到最小，不要把它關掉。
5. 黑色狀態視窗會顯示學生觀看網址、觀看人數和流量。要結束直播時，按 `Q` 或直接關閉這個視窗。

直播期間，程式會讓螢幕保持開啟，避免螢幕休眠後學生看到停住的畫面；結束後恢復原本的電源設定。

## 第二教師機（選用）

雙擊 **`lite-teacher2.bat`**。第一次會詢問主教師機的 IP，輸入後按「開始分享畫面」即可。這台電腦的畫面會出現在「教師 2」頻道。

## 學生電腦

- 開 Chrome 或 Edge，進入 `http://主教師機IP:8080/`。網址會顯示在主教師機的黑色狀態視窗上。
- 也可以用派送軟體，把啟動後產生的 `deploy\教室直播.url` 發到學生桌面，或做進還原卡的母片。
- 播放頁功能：
  - **子母畫面**（`P`）：小視窗會浮在編輯器上方。
  - **半螢幕**：按 `Win + ←／→`。
  - **滾輪放大**：放大游標所在位置，放大後可以拖曳移動；雙擊可放大 2 倍或還原。
  - **切換教師**：按 `1`／`2`。
  - **重新連線**：按 `R`。斷線時也會自動重連。

## 疑難排解

| 狀況 | 處理方式 |
|---|---|
| 學生顯示「無法連線到教師電腦」 | 確認學生電腦 ping 得到主教師機；重新啟動一次，讓程式重新設定防火牆。 |
| 學生顯示「尚未開始直播」 | 確認教師端已按「開始分享畫面」。 |
| 字太糊 | 教師端改選「高畫質」，也建議把 VS Code 放大到 125–150%。 |
| 部分學生卡頓 | 教師端改選「省頻寬」。也請檢查交換器之間的串接線是否為 Gigabit。 |
| 「埠 8080 已被使用」 | 先關閉其他直播程式；也可以在 `settings.psd1` 修改 `HttpPort`。 |
| IP 選錯或偵測錯誤 | 重新啟動後在網卡清單選正確的；或在 `settings.psd1` 的 `ServerIP` 直接填入正確 IP，之後就不會再詢問。 |

## 使用的連接埠

只用 TCP 8080。
